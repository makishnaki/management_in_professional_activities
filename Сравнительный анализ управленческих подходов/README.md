# «ВкусВилл» и «Лента»

«ВкусВилл» — известен культурой доверия к сотрудникам, децентрализацией, открытостью и фокусом на обратной связи от покупателей; много локальных решений на уровне магазинов. 

«Лента» — крупная сеть с централизованным управлением, жёсткими стандартами, KPI и операционными процессами. 

## 1. Характерные черты

| | черта | вкусвилл | лента |
| :--- | :--- | :--- | :--- |
| 1 | Управление | Обратная связь, реакция на жалобы | Стабильные поставки, отсутствие дефицита товаров |
| 2 | Скорость принятия решений | Децентрализация  быстро подстраивается под локального покупателя | Все решения принимаются в головном офисе |
| 3 | Взаимодействие с персоналом | Культура доверия, отсутствие штрафов | Строгие правила, контроль качества |
| 4 | Клиентоориентированность | Прямая связь, лояльное комьюнити | Акции, скидки, карта лояльности |

## 2. Эффективность

* **ВкусВилл:** вкусвилл эфективен как супермаркет у дома. Сотрудники не подчиненные, а как соавторы. 
* **Лента:** лента эффективна для масштабного формата. Высокая дисциплина и контроль дают производительность.

## 3. Вывод

Главная черта - баланс между гибкостью и дисциплиной, для каждой модели нужен свой подход
